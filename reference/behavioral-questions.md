# 行为面试题库（STAR + 软素质）

> 本文件是 `SKILL.md` 行为面试与 HR 轮次的展开题库；执行时以 `SKILL.md` 为准。
> 行为面试考察**软素质与真实经历**，大厂（尤其字节、外企 Leadership Principles 体系）权重很高。
> 面试官必须用 **STAR 追问法**逼出细节，识别"背模板"与"真经历"。

---

## STAR 追问法（面试官必须掌握）

候选人回答行为题时，容易停留在笼统叙述（"我们团队协作很好""我推动了这个项目"）。
面试官必须沿 STAR 四要素逐层逼问，直到还原出**具体的、可验证的个人行为**：

| 要素 | 追问方向 | 识别信号 |
|------|---------|---------|
| **S**ituation 情境 | "当时具体什么背景？什么时间？团队多大？" | 说不清背景 → 可能是编的 |
| **T**ask 任务 | "你个人的目标/职责是什么？为什么是你来做？" | 只说"我们" → 挖不出个人贡献 |
| **A**ction 行动 | "**你具体做了什么**？为什么这么做？有没有别的选择？" | 只讲结果不讲过程 → 可能非主导 |
| **R**esult 结果 | "最终结果如何？有数据吗？事后有没有复盘？" | 无量化、无反思 → 深度不足 |

**追问铁律**：
- 候选人说"我们"，必须追问"**你**具体做了什么"——分离团队成果与个人贡献
- 候选人给结论无过程，必须追问"当时你是怎么权衡/决策的"
- 候选人无量化，必须追问"有没有具体数字/前后对比"
- 与技术追问同样遵守 `topic_round == 5` 锁死

## 能力项题库

### 1. 影响力 / 推动力（Ownership & Drive）

| 题目 | 考察点 | STAR 追问链 |
|------|--------|------------|
| 讲一个你主导推动、并最终落地的事情 | 主动性、结果导向 | 为什么是你推 → 遇到的最大阻力 → 你怎么突破 → 最终量化结果 |
| 讲一件超出你职责范围、但你主动去做的事 | Ownership | 为什么主动做 → 别人怎么看 → 有没有影响本职 → 收益 |
| 你推动过哪个技术决策被团队采纳？ | 技术影响力 | 方案对比 → 怎么说服他人 → 落地后效果 → 有无反对声音 |

### 2. 冲突处理 / 跨团队协作（Collaboration）

| 题目 | 考察点 | STAR 追问链 |
|------|--------|------------|
| 讲一次你和同事/上级有技术分歧的经历 | 沟通、说服、妥协 | 分歧点 → 你的立场依据 → 怎么沟通 → 最后怎么决 → 复盘 |
| 讲一次跨部门协作中遇到阻力的经历 | 跨团队推动 | 阻力来源 → 你怎么对齐目标 → 用了什么手段 → 结果 |
| 和难沟通的人合作，你怎么处理？ | 情商、协作韧性 | 具体的人/事 → 你的应对 → 关系变化 |

### 3. 抗压 / 故障应对（Resilience）

| 题目 | 考察点 | STAR 追问链 |
|------|--------|------------|
| 讲一次线上重大故障，你是怎么处理的 | 抗压、应急、复盘 | 故障影响面 → 你第一步做什么 → 定位过程 → 止损手段 → 事后改进 |
| 讲一次 deadline 极紧张的项目 | 压力管理、取舍 | 时间压力多大 → 你怎么排优先级 → 砍了什么 → 结果与代价 |
| 讲一次你犯的严重错误 | 诚实、复盘能力 | 错误是什么 → 造成什么影响 → 你怎么补救 → 学到了什么 |

### 4. 失败 / 复盘（Learn & Be Curious）

| 题目 | 考察点 | STAR 追问链 |
|------|--------|------------|
| 讲一个你做失败的项目 | 诚实、反思深度 | 失败标志 → 根因分析 → 你的责任占比 → 现在会怎么做 |
| 你最近主动学的一项新技术是什么？ | 学习主动性 | 为什么学 → 怎么学 → 用到哪 → 踩了什么坑 |
| 收到过最难接受的反馈是什么？ | 开放度、成长性 | 反馈内容 → 当时反应 → 后续改变 |

### 5. 职业动机 / 稳定性（多用于 HR 轮 & 收尾）

| 题目 | 考察点 | 注意信号 |
|------|--------|---------|
| 为什么想离开现在的团队 / 为什么看新机会？ | 动机、稳定性 | 只吐槽前东家 → 减分；能说清成长诉求 → 加分 |
| 未来 1-3 年的职业规划是什么？ | 目标清晰度 | 与岗位方向是否匹配 |
| 你选 offer 时最看重什么？ | 价值观匹配 | 只看钱 / 只看成长，均需追问背后逻辑 |
| 你期望的薪资范围？（仅 HR 轮，模拟练习点到为止） | 谈判意识 | 提示：给区间、有依据、留弹性 |

## HR 轮 / 非技术环节（仅 `round_type == hr` 或收尾触发）

HR 轮是拿到 offer 的最后一关，考察**动机、稳定性、价值观匹配、薪资预期**，不再深挖技术。
模拟时保持轻量，重点给候选人**反馈"哪些回答会踩雷"**：

- **离职动机**：避免单纯抱怨前东家；用"寻求 X 方向成长"正向表达
- **稳定性**：频繁跳槽需主动给出合理解释
- **薪资谈判**：给区间而非单点、有市场依据、为 base 之外的项（股票/奖金/职级）留空间
- **职业规划**：与目标岗位方向自洽

## 行为面试评分归属

行为面试**不单设权重维度**，其表现按内容映射到既有维度（见 `reference/score-rubric.md`）：

| 行为表现 | 计入维度 |
|---------|---------|
| 问题拆解、决策逻辑、复盘自洽 | 思维逻辑 |
| 表达条理、STAR 结构清晰度 | 表达能力 |
| 主动学习、反馈接受度 | 学习能力 |
| 真实项目中的 Ownership、量化结果 | 项目经验 |

此外，报告的「录用建议」章节应综合行为表现给出**软素质定性观察**（如"Ownership 强 / 抗压一般 / 复盘偏浅"）。

## 反问环节评估（收尾前必做）

反问是**双向考察点**：既让候选人了解团队，也反映其**思考深度与求职诚意**。

**面试官动作**：
1. 主动邀请："面试到这里基本结束，你有什么想问我的吗？"（话术随风格调整）
2. 记录候选人反问，并在报告中简评其质量

**反问质量分档**：

| 档位 | 表现 | 示例 |
|------|------|------|
| 优秀 | 针对团队技术挑战/业务方向/成长路径，有信息含量 | "团队现在最大的技术债是什么？""这个岗位半年内的核心目标？" |
| 一般 | 常规但合理 | "团队规模多大？""技术栈是什么？" |
| 偏弱 | 只关心待遇/加班，或答不上来"没什么想问的" | "会不会经常加班？"（可问但不宜作为唯一提问） |

**给候选人的示范建议**（写入报告改进建议）：准备 2-3 个体现技术思考的反问，避免"没有问题了"。
